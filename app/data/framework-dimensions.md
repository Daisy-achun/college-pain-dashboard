# 大学生切面维度（Workforce of One → 校园版）

来源：《Workforce of One》中文翻译合集——方法一「细分员工群体」。

## 底层逻辑（必须守住）

1. **海伦与吉尔**：国籍/性别/职位/绩效可以相同，目标、学习风格、动机、需求仍可截然不同 → 不能只按「学校标签」一刀切。
2. **细分是为了定制实践**：HR（或产品）为 Group A/B/C 准备不同实践，不是贴完标签就结束。
3. **维度要满足**：可观察/可自报；切开后痛点真的不同；能指导下一步差异化内容。
4. **每个场景只切 2～3 刀**，选「痛点会分叉」的维度；心理负荷常作调节变量，慎作唯一主切。
5. **文案与 case 必须来自整帖语义**（身份处境 + 场景 + 卡点），禁止「出现 985 二字 = 名校 case」。

## 维度映射表

| WoO 原维度 | 大学生映射 | 切面取值（示例） | 什么时候用来切 |
|---|---|---|---|
| 人口特征·教育程度 | **学历位置** | 名校(985/211) · 双非/普本 · 专科/专升本 | 升学、求职、实习几乎全场景 |
| 与组织的关系·职业阶段 | **与学校的关系位置** | 保研边缘/有名额 · 挂科重修风险 · 延毕风险 | 保研分叉、考试、论文 |
| 地理因素 | **城市与地理资源** | 一线可及 · 非一线/想回家乡 · 校区偏远 | 实习、秋招、去向 |
| 工作角色·专业领域 | **专业路径** | 热门赛道 · 「天坑」/冷门 · 医/法高沉没成本 | 转专业、方向、就业 |
| 价值（高潜/紧缺） | **路径资本** | 履历厚 · 履历空白/刚起步 | 实习、保研材料、秋招 |
| 价值观与行为·动机 | **家庭叙事与支持** | 第一代/经济压力 · 要稳定(考公) · 能支持探索 | 岔路、留学、offer |
| 健康 | **心理负荷** | 功能尚可 · 高强度焦虑/精疲力竭 | 横切调节；宿舍孤立等场景可主切 |
| 个性（学习/关系风格） | （数据弱，暂不作主切） | — | 有稳定信号再补 |
| 拟招聘人员 | **准大学生/高考志愿** | （本产品偏在校） | 入学前另册 |

## 高频场景怎么定

用 `dashboard.json` 里大一～大四的主题/场景计数：取**大部分人会撞上的节点**，砍掉小众支线（如单独「留学申请」「离校手续」不进主干四格）。

| 年级 | 场景（约 7 个/级，按帖量加厚） | 数据依据（摘要） |
|---|---|---|
| 大一 | 转专业；宿舍舍友；考试绩点；**学校管理**；社团学工；四级；没方向 | T17 场景量第一；宿舍/考试/T15/学工/迷茫紧随 |
| 大二 | 挂科重修；第一份实习；职业方向；看别人有实习；**转专业落地**；竞赛实验室；学校管理 | T03/T02/T17 + 转专业与竞赛场景仍高 |
| 大三 | 保研or考研；**保研材料**；考研；实习加深；就业准备；**考公考编**；竞赛冲刺 | T08/T11 分列前二；实习考研并高 |
| 大四 | 秋招；Offer；论文；考研收尾；**求职×论文并行**；导师关系；**离校手续** | 求职断档第一；论文/考研/T23 手续同级 |

## Case 匹配纪律

- 先读整帖：说话人是谁、卡在哪个动作、和切面是否同一处境。
- 名校切面要用「名校处境下的痛」（如保了也不值、光环仍 0 offer），不要只用「正文出现 985」。
- 双非切面要用双非约束下的选择（培训/考研洗脑、简历关），不要混进「双非标签但叙事是 985 硕」的帖当双非代表（除非切面就是本硕落差）。

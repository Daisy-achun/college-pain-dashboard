# 三平台小样本采集状态

目标是知乎、小红书、快手各 100–300 条大学生相关内容。当前已完成公开候选检索，但还没有把候选误报成正文样本。

知乎通过公开搜索结果找到 5 个大学生痛点问题，见 `sample_candidate_manifest.csv`。未登录打开其中一个问题页时能看到题目摘要和 1 条可见回答，但这不是稳定的批量接口；现有 `tool/crawlers/zhihu.py` 能按问题 ID 分页抓回答，但要求账号持有人授权的合法登录态。没有该登录态时会返回空列表，遇到 401/403/412/429 或验证码会熔断。

小红书搜索页本身可以打开，但随后出现“登录后查看搜索结果”的登录弹窗，没有向只读浏览器暴露笔记链接或正文；快手搜索页可以打开，但没有暴露视频链接/正文并提示登录。搜索摘要只能作为标题证据，不能替代正文，也不会被计入 100–300 条样本。两个平台应使用平台允许的公开导出/API，或先提供 URL 清单再做只读小样本。

因此当前实际完成量是：知乎 0 条正文、小红书 0 条正文、快手 0 条正文。下一步需要一个外部状态变化：知乎浏览器完成登录，或三个平台注册 API/导出数据/公开 URL 清单。不会通过登录态签名提取、验证码、指纹模拟、住宅代理或其他手段规避平台限制。

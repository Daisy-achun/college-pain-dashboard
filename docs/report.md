### 1.3 处理流程

1. **规则相关性**：同时满足两个条件才算相关。
   - 有痛点词或求助句式。
   - 有学生身份线索；牛客和豆瓣按上下文判断。
2. **降噪分类器**：
   - 训练数据：人工标注 465 条 B站/虎扑/牛客/豆瓣样本（噪声/有效）。
   - 模型：bge-small-zh 向量加手工特征的逻辑回归。
   - 用法：保留 p_noise<0.6 的条目。
3. **聚类**：对保留的 2,744 条做 KMeans（K=40），再人工合并命名为 25 个主题。T25 是"面经/经验分享（非吐槽）"，已排除。
4. **主题人工抽检与二次清洗**（应主 agent 抽检要求）：
   - 每个主题随机抽 20 条，共 480 条，逐条人工判读：Y=符合主题，W=是学生痛点但主题错，N=无关、非学生、广告或建议类回复。
   - 每个主题加"主题关键词闸门"（例如 T23 必须出现挂科/补考/重修/学分等）。
   - 再加三条过滤：去掉"非学生"（工作 N 年、社招、高中生、替亲戚问）；去掉"攻略/面经/推广"；B站和虎扑去掉没有第一人称的建议类回复。
   - 人工判 N 的剔除，判 W 的移出该主题。
   - 例如抽检中发现的《碧蓝之海》动漫评论（被误归 T23），已剔除。
   - 结果：痛点集 2,744 → **2,369**；进入主题的条目 1,875。
5. **标签**（规则加推断）：阶段、场景（21 类）、学生类型（15 类）、情绪强度（1–3）、语态（自述/吐槽、求助/困惑、回复/建议）、gap 规则标签（11 类）。
   - 牛客的学校层次和届别取自公开用户卡片，只保留层次，不保留校名。
   - 牛客"26届"之类的届别会结合抓取日期推断阶段（共 455 条）。
6. **Gap 人工编码**：按来源分层抽 245 条，逐条阅读编码，其中 155 条有效。

**归纳出的 6 类学生画像：**

1. **名校（985/211）学生**：偏向保研/推免（×1.8）、行业与方向选择、"信息差/早知道"（×1.4）。痛点是"选择太多、怕选错"和"光环失效"，而不是缺机会。
2. **双非/普通本科**：学历被筛（×1.6）、找实习（×1.3）、秋招（×1.3）。最大的痛是"努力了但卡在简历关"。
3. **专科/专升本/三本民办**：专升本（×6.0/×18）、学历歧视（×2.6）、家庭经济（×1.5）。前半程的痛是"落差与升本挣扎"，后半程是"求职碰壁"。
4. **研究生**：导师关系（×2.9）、毕业论文/延毕（×2.4）、科研。痛点是"被制度卡住、主动权不在自己手里"。
5. **特定专业生**：
   - 师范生：考编（×5.7）。
   - 医学生、法学生：专业不喜欢/转专业（×4.5–4.7）。
   - 计算机/理工科：方向迷茫（×1.7）、专业选择。
   - 文科/商科：考公（×2.0）、学历（×1.6）。
6. **农村/第一代大学生、女生**：
   - 第一代：家庭经济压力（×7.4）、考公（×3.6），并且常提到"家里给不了建议"。
   - 女生：室友人际（×2.4）、家庭（×1.9），还有求职性别歧视（T08 中女生 33 条）。

样本量提醒：医学、师范、法学、农村/第一代、女生各只有 27–74 条，"985/211" 和 "双非" 有一部分来自牛客用户卡片（且 211 名单不全，双非可能被高估），结论只作方向参考。

## 4. 主要痛点聚类（按估计有效条数排序；每类附 3–5 条原文）

### 1. T01 秋招/春招投递受挫、0 offer 与焦虑失眠

清洗后 204 条，估计有效约 173 条，置信：高。

情境：毕业季（尤其 9–11 月和春招尾声）大量投递，简历挂、笔试挂、面试挂，看到别人拿 offer。痛在哪：自我否定（"是不是废物"），失眠、反复刷招聘 App，害怕"毕业即失业"。几乎全部来自牛客，大四/毕业季占绝大多数，情绪强度≥2 的比例最高（78%，清洗前统计）。

> 「秋招实在是太焦虑了，尤其是已经到了这个时候了，还是没找到工作，整宿整宿地睡不着，一闭上眼睛就开始焦虑，明天要是还没有公司约面试我该怎么办，笔试要是又没过该怎么办，还有什么公司我能投，如果毕业真的没工作怎么办...……一个秋招过去，感觉自己头发都愁白了，唉……」

## 6. "此刻的我"情境类型（第一版）

### 6.1 生成维度（Workforce of One 思路：用少数维度组合出可复用的情境模块）

- **维度 A 阶段**：入学前/大一 → 大二 → 大三 → 毕业季 → 研究生 → 毕业后。
- **维度 B 问题性质**：
  - ① 方向未定（不知道要什么）
  - ② 路径已定但不会走（知道要什么，不知道怎么做/规则）
  - ③ 外部受阻（导师、学校、学历筛选）
  - ④ 受挫重来（失败后的再选择）
  - ⑤ 关系与归属
- **维度 C 资源禀赋**：学历层次（名校/双非/专科专升本）× 家庭支持（能指导/不能指导/施压）× 有无引路人。
- **调节变量**：情绪强度（1–3）。强度 3 的 152 条需要先做情绪托底，再给信息。

## 7. 对产品的初步启示（供讨论）

1. **大三前后的"岔路口 + 第一份实习"是最大的入口**（S3+S4+S5，合计约 700 条估计有效）。路径闯关应该从大二起把"实习时间线、技能包、简历节点"前置。
2. **大一大二最缺的是"自我认知 + 低成本试错"**（S1、S2），而不是更多攻略。适合用 Dream/了解自己 + 线下小任务点亮。
3. **"过来人结合我的情况说两句"是高频需求，但供给很少**，第一代大学生尤其明显。可以做"同类背景学长"匹配：按学校层次、专业、目标方向匹配。
4. **规则类信息**（三方、违约、保研夏令营、秋招 vs 实习时间线）很适合结构化成"规则卡"，在相应时间点推送。
5. **研究生是一条单独的线**（导师、论文、延毕、导师不放实习）。

## 8. 局限性（请务必阅读）

1. **来源偏差大**：
   - 最终痛点集里牛客占 63%（1,491/2,369）。牛客是求职社区，**结果明显偏向求职（尤其计算机/互联网方向）和毕业季**。
   - 低年级、生活、人际、心理类痛点主要来自 B站、虎扑、豆瓣，样本少，被低估。
   - **知乎、小红书、抖音、贴吧、微博都没有覆盖**。这些平台（尤其小红书）女生、文科、低年级和情绪类内容更多，可能改变排序。
2. **B站游客限制**：每个视频只能拿到约 12 条热评，评论偏向"高赞、讲道理"的回复，个人求助偏少。
3. **豆瓣只部分覆盖**（13 个话题，其中 11 个只有楼主摘要，人工转录），不能代表豆瓣整体。
4. **噪声与标签精度**：
   - 主题精度见 1.4 节，低置信主题只能看方向。
   - 阶段、场景、类型、gap 标签是规则判定，召回有限。
   - 211 名单不完整，牛客卡片的"双非"可能被高估。
5. **时间与日期**：
   - 数据跨 2015–2026，以 2022–2026 为主。
   - 虎扑日期是相对时间（"2月前"），已按抓取日 2026-10-08 换算成近似日期（标为 ≈）。
   - 豆瓣部分条目缺日期。
6. **研究生和已工作者**：研究生内容保留（也是 wowland 潜在用户）。已工作者多数已过滤，但"毕业后回望"类保留为经验素材，可能有少量漏网。

## 9. 文件说明

- `raw_posts.csv`：全部 10,867 条清洗后条目。主要字段：
  - 基础信息：`id, source, url, date, text, context_title`（视频/帖子标题）, `search_kw, is_reply`
  - 筛选结果：`relevant_rule, kept_pain`（分类器保留）, `p_noise, manual_noise, kept_pain_clean`（**最终痛点集**）
  - 主题：`theme_orig`（KMeans 主题）, `theme_clean`（人工校验后主题）, `theme_drop_reason, kmeans_cluster`
  - 标签：`stage, stage_inferred, scene, student_type, school_tier_profile, gap_rule, gap_manual, emotion_1to3, voice`
  - 多选标签以 `;` 分隔。
- `themes.csv`（聚类主题概况，清洗前）、`analysis/theme_precision.csv`（各主题精度）、`stage_scene.csv`（阶段×场景矩阵）、`gap_sample_coded.csv`（245 条 gap 人工编码）、`noise_labels.csv`（465 条噪声标注）。
- `analysis/theme_hand_codes.txt` + `analysis/theme_check_ids.csv`：480 条主题抽检记录。`analysis/quotes_final.md`：报告引文清单（含 id）。
- `crawl/`：爬虫脚本与关键词。`raw/`：原始抓取数据（jsonl）与豆瓣人工转录文本。

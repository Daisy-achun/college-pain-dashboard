## 一页结论

（口径：全渠道主口径 **10,302** 条；含百度贴吧标题、V2EX、知乎新抓取样本。痛点主题 **34** 个，场景 **23** 类可多选。估计有效 = 条数 × 清洗后精度。）

1. **有年级信息的帖子里，大四/毕业季最多（1,760 条），核心仍是「从学校走向工作的那一步」。** 秋招 0 offer（T01）、找不到实习（T02）、升学还是就业（T08）、offer 怎么选（T05）合计估计有效约 **1,367** 条；再加上就业方向迷茫（T03）与学历被筛（T04），约 **2,219**，占全部主题估计有效（约 **9,012**）的 **25%**。学校层面问题（管理、宿舍、食堂、教学、收费、强制实习、毕业手续，T17–T23）合计估计有效约 **2,432**（**27%**），主要来自大学生活质量指北与厅长信箱——来源偏差会抬高「校园生活/管理」比重。

2. **低年级痛点是心理状态、学校管理与生活条件、方向感，而不只是「缺攻略」。** 入学前到大二共 **1,486** 条：心理场景 455、学校管理 435、宿舍条件 294、课业挂科 282、职业方向 271、方向迷茫 214；情绪强度≥2 占 **39%**。主要来自 CollegesChat、贴吧标题、X。

3. **「卡在导师/学校/制度」是独立大类。** 毕业论文与导师（T13）+ 导师不放实习（T14）共 **593** 条（估计有效约 **539**），其中 **364** 条标为研究生阶段。本科侧对应挂科重修（T16）、学校管理过严（T17，条数第一）、毕业证/档案手续（T23）。

4. **出身与学历是贯穿变量。** 专科生提到「学历/出身/歧视」场景的比例约为全体的 **2.4 倍**；专升本/学历落差（T12）**410** 条。名校学生更偏保研、推免、升学就业岔路与行业选择。保研/推免（T10+T11）合计 **476** 条，保研论坛贡献集中且偏旧帖。

5. **心理与关系是横切层。** 场景上「心理：焦虑/抑郁/自我否定」**2,258** 次命中（可多选，最高），室友人际 **804**；主题上室友矛盾 T24 **674**、意义感 T25 **418**、心理健康 T26 **235**。情绪强度 3 共 **570** 条（**5.5%**），在好心情、壹心理、X 中占比最高。

6. **Gap 的本质不是「信息太少」。** 人工深读有效 **219** 条里，除纯情绪出口（24%）外，前位是：怕选错（21%）、不了解真实路径样子（14%）、需要个性化判断（12%）、不了解自己（11%）、不懂规则时间线（10%）。信息过载仅约 **5%**。全库规则 gap 命中约 **1,472** 条，Top 为怕选错、缺引路人、没人结合情况说。

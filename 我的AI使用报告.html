2. 每类真实案例

① 产品从 0 到 1 开发与 UI 迭代

案例 A · MoonWave 月潮 APP（2026-08-27～09-05）
想完成：做潮汐/经期记录向的纸浮雕风格 APP；探索页七岛航行、正念/统计页统一视觉。
AI 帮了：按设计图与小红书参考实现 UI；生成纸浮雕素材；改交互（如去掉螃蟹）；同步 GitHub / Vercel。
是否采用： 部分明确采用 对话中有「认可！！！好好看！！」「一比一还原设计图」等继续指令；也有「螃蟹效果不是很好 → 去掉吧」的否决。最终上线与留存情况：需要本人补充。
案例 B · 小咪体重秤 Web APP（2026-10-15～10-19）
想完成：为 AI 原生硬件做 iPhone 框网页 APP（首页宠物、测量、陪伴 Agent、发现、部署上线）。
AI 帮了：按设计图搭页面与架构；接大模型陪伴；生图/抠图；部署域名；周末后要求「复盘 build 时间线与完整对话」并上传私密仓库。
是否采用： 高密度迭代并部署 多次要求同步改本地与 aidol.dufengyun.xyz；并专门做开发复盘文档。硬件蓝牙「为什么没连上」在记录中未闭环：需要本人补充最终是否连上。

② GitHub / 部署 / 工程交付

案例 A · VERSO 多平台部署（2026-10-04 密集）
想完成：把 chx0506/VERSO 部署到 Vercel / CloudBase 并拿到可访问链接。
AI 帮了：定位本地路径、走 CLI 部署、切换方案（CloudBase ↔ Vercel）。
是否采用： 过程采用，结果需核对 同一目标触发多段会话；公开 URL 是否稳定可用：需要本人补充。
案例 B · GitHub 主页与仓库介绍（2026-10-19～10-24）
想完成：学习他人 README 写法，写自己的详细自我介绍；给缺少介绍的仓库补描述。
AI 帮了：起草/改写介绍；按反馈纠正身份误写（「我不是华一明」）、代表作列表（专注羊、VERSO、小咪、MoonWave）等。
是否采用： 持续改到符合个人设定 多轮纠正后仍要求继续优化短描述，推断已写入仓库；线上最终版：需要本人补充。

③ 视觉素材、配图与论文架构图

4. 主要帮助、未解决问题与中途停下的迹象

主要帮助（有记录支撑）
  • 把模糊产品直觉快速落成可点的网页/APP 原型
  • 按参考图做视觉与素材，缩短设计实现鸿沟
  • 代劳 GitHub / 部署 / 域名等交付琐事
  • 把一次性流程固化成 Skill，便于下一场活动复用
  • 用通俗语言解释后端、并发、代码阅读路径
  • 竞赛/实习向的文档、介绍、复盘沉淀
记录中反复未闭环的问题
  • 严格「顶会论文流程图」质感：多轮仍觉风格单一/排版叠字
  • 硬件侧：蓝牙连接、秤数据帧等待（「为什么没连上」）
  • 能力边界：本地 PPT / Codex computer use 期望与实际不一致
  • 云端预览 vs 本机打开：portfolio「打不开/空白」
  • 科研代码体量大时「看不懂」的学习摩擦
  • 生图式猫咪与用户上传真猫「差别很大」类一致性问题

可能中途放下的原因（仅基于记录可观察的迹象，非心理推断）

  • 活动节奏切换：火种 → Skill 平台 → MoonWave → 知乎 → 小咪 → 大学生研究，时间线呈「一场冲刺接一场」，后一项目开始后前一项目会话显著变少——更像赛程切换，是否「放弃」需要本人补充。
  • 明确否决后搁置：如 MoonWave 螃蟹交互「效果不是很好，之后有需要再加上」——属于有意识砍功能。
  • 质量门槛未过线：论文图多次「不行啊 / 效果还变差」后继续打磨 Skill，说明未轻易接受当前输出；是否最终换工具手动画：需要本人补充。
  • 环境与权限摩擦：Vercel token 失效、本机/云端预览不一致、蓝牙权限等导致同一目标拆成很多短会话，可能拖慢收尾。
  • 单会话起势未见续聊：如 PairRead 双语阅读 PRD→网页原型、Swift 改 iOS 等——后续在索引中变少；是否已在其他工具继续：需要本人补充。

5. AI 对你的角色与定位

综合使用习惯，Cursor AI 在你这边更像：

  • 黑客松 / 周末冲刺的全栈执行搭档——从 PRD、UI、素材到部署一条龙，默认「你定方向，它落地」。
  • 带审美标准的实现工——频繁「参考图片一比一还原」「缺素材自己生成」「用 design-taste」；你负责品味裁判，它负责赶工。
  • 工作流沉淀器（Skill 工程师）——做完一件事就要求封装成 Skill / 上传仓库，下一次少从零开始。
  • 交付与运维助理——GitHub 介绍、协作者、Vercel/域名、复盘文档，偏「收尾官」。
  • 耐心的技术翻译——在 Veritas/SFT、Vercel 并发等话题上明确要求「计算机小白能听懂」。
  • 不是：完全自主的科研实验主导者（你仍要不断纠正方法图与代码理解路径）；也不是可靠的硬件现场操作员（蓝牙/本机外设类任务摩擦大）。

一句话：你把 AI 定位成「有审美约束的产品实现与交付副驾驶」，自己保留选题、品味否决权和对外叙事；当任务跨出软件界面、进入硬件现场或极高标准学术可视化时，副驾驶位会明显抖。
